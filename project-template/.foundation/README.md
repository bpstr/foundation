# Foundation-managed files

This directory contains shared guidance and project profiles installed from `bpstr/foundation`.

Rerunning the Foundation installer may replace files in this directory. Put project-specific knowledge in the root `AGENTS.md`, `foundation.yml`, `.specs/` and project scripts instead.

`AGENTS.md` tells coding agents how to apply the selected profile from `foundation.yml`. Managed profile guidance is stored under `profiles/`; for example, SaaS projects use `profiles/saas.md`.

`source` records the repository and ref used by the most recent installation.
